# NIFTY 100 FINANCIAL INTELLIGENCE PLATFORM

Nifty 100 financial analytics platform built with Python, Pandas, SQLite, Streamlit and Plotly.

## Dashboard

8 screens: Home, Profile, Screener, Peer Comparison, Trends, Sector Analysis, Capital Allocation and Annual Reports.

## Run Dashboard

python -m streamlit run src/dashboard/app.py

## Valuation Engine

python src/analytics/valuation.py

Outputs: output/valuation_summary.xlsx and output/valuation_flags.csv

## Database

data/nifty100.db
